# Ruta 1 — Web

Landing page for **Ruta 1**, the San Fernando municipal bus app.

Built with React 19 + TypeScript + Vite.

## Stack

- React 19, TypeScript, Vite 8
- Fonts: [Fraunces](https://fonts.google.com/specimen/Fraunces), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) (Google Fonts CDN)
- Icons: [Material Design Icons](https://cdn.jsdelivr.net/npm/@mdi/font) (CDN)
- No router, no state management library, no data fetching layer

## Commands

```bash
npm run dev       # Start dev server with HMR
npm run build     # Type-check + production build (output: dist/)
npm run lint      # ESLint
npm run preview   # Serve the production build locally
```
